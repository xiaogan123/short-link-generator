# Project instructions

Build a neutral desktop link-management application. Do not copy code from private projects. Public source uses example.com and example.org for sample data. Never place credentials, private hostnames, user data, local machine paths, private prompts, or screenshots containing private data in this repository.

Follow docs/CONTRACT.md for the desktop bridge. Work only in assigned files; collaborators share this tree. Do not revert another contributor's changes. No subdelegation unless the coordinator explicitly authorizes it.

No live cloud writes, push, release, hosted CI triggers, or production changes during local development. All audits use GPT-6. Test results and limitations must be accurately reported. Native Windows and Intel macOS validation cannot be inferred from ARM macOS builds.
