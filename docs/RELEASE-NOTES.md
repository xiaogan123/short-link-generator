# 0.1.1 候选版

本轮改进桌面界面、表单引导和中文说明。链接管理更紧凑，常用操作更容易找到；邀请码、平台地址和检测结果采用更直接的名称。现有链接和云端跳转规则继续兼容。

本地候选包与实际验收平台以随包记录为准。macOS Apple 芯片本机验证不能代替 Intel macOS、Windows 或最低系统版本验证。当前未配置正式自动更新渠道，也未完成公开发行。

## 验证说明

- 修改云端前仍需核对并确认操作范围。
- 本机检测、短链接跳转检查和可选大陆检测分别展示，不把未知结果当作可访问。
- macOS 使用临时签名，未经过 Apple 公证。
- 正式发行前仍需完成各平台原生验证、隐私检查、签名配置和下载验证。

# 0.1.0 候选版

首个候选版本提供账户管理、域名检查、短链接编辑、地区分流、共用平台地址、网址检测、可选定时监测及配置找回。
