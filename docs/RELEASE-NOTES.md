# 0.1.11

修复旧版检测密钥操作缺少本机服务配置时，修复入口无法继续的问题。现在先核验并找回本机检测配置，再由用户单独确认密钥修复。找回配置只读取云端，已有短链接、密钥和待处理记录保持不变；找不到或无法确认时会说明原因。

恢复提示明确显示对应账户，区分检测密钥与 Cloudflare API 令牌，历史操作详情默认收起。无需因为检测密钥提示而删除并重新导入账户。

本版同时包含下述 Mac 本机授权改进。实际重启、升级及各平台验证结果以正式发行记录为准。

# 0.1.10

Mac 旧账户增加「更新本机授权」。确认后重新保存并核对本机凭据，普通操作不再反复读取旧版条目。处理失败会停止并保留继续处理的入口，已有云端配置、短链接和恢复记录保持不变。首次通过 API 令牌连接的新账户直接使用新的保存方式。

账户页与域名窗口会明确提示需要处理的账户，保留原来填写的内容；完成授权后由用户重试原操作。系统钥匙串锁定或自定义访问限制仍可能要求系统授权。真实重启、升级和各平台验证结果以正式发行记录为准。

# 0.1.9

平台地址改为全局共用，所有已导入账户和域名都可直接选用，不再需要勾选同步账户。首次创建链接时自动配置所需地址；更新平台后，已使用的账户会一起更新，各条链接的邀请码保持不变。配置失败时保留可继续处理的记录，避免短链接先保存却缺少平台配置。

域名接入会连贯准备下一步：缺少网站解析时直接显示修改确认，提交后继续检查目录，避免在检查页面之间反复点击。修改仍需明确确认，已有网站、邮件和验证记录仍受保护。

开启网站代理前会检查整个域名的邮件和服务设置。如果该地址同时用于邮件或其他服务，会停止自动修改并说明原因；确认后的配置变化也会重新核对，避免影响原有服务。

解析写入被 Cloudflare 拒绝时，错误和处理入口保持可见。账户已连接只代表可以读取资源；自动补齐解析还需要该域名的 DNS 编辑权限。补好授权或在客户端更新令牌后，可保留原填写内容继续；软件不会自行增加权限或反复尝试写入。

凭据缓存按使用情况续期，30 分钟未使用或从系统读取、更新后满 8 小时停止复用，减少连续使用时的重复系统授权。不存在的检测密钥会短时记住查询结果。凭据仍保存在系统凭据库，缓存会在后续读取、定期清理及相关更新时失效，关闭应用后不再保留；首次使用、软件更新或系统重新要求授权时仍可能弹窗。

Mac 版本改用固定的应用签名身份，避免以后每次更新都被系统当作身份不同的应用。首次从旧版升级仍可能需要重新允许访问凭据；此后保留同一身份。钥匙串锁定或用户仅允许单次访问时，系统仍可能询问。此变化不关闭系统保护，也不把令牌改成明文保存。

查看平台检测状态时，未开启检测的账户会直接显示“未启用大陆监测”，不再读取这些账户的凭据。网站检查结果用“大陆访问地址 1、2”区分地址，避免显示难以理解的内部编号。

检测密钥的更新增加可恢复流程：先安全保存，再更新云端。中途失败会保留处理入口，旧版遗留的“云端已更新、本机保存失败”也可按提示修复，避免反复重置或误报检测已就绪。

保存前会检查目标网址长度和端口，避免保存后无法跳转。

提交修改时会防止重复操作，处理完成后再开放返回和关闭。取消检查后，迟到的结果不会重新弹出确认窗口；平台地址保存失败时，错误会直接显示在编辑窗口中，并保留填写内容。

找回云端配置时会重新核对平台地址，避免把旧记录当作已同步。清理账户专用资源时，会识别并清除已无关联的检测记录；仍有短链接、未知配置或其他服务使用时会停止清理。

各平台安装及真实域名验收结果以本版本 Release 记录为准。

# 0.1.6

修复刷新域名列表时读取多个账户、连续请求系统授权的问题。现在只读取所选账户；多账户时会先请你选择，处理中显示等待提示，重复点击不会继续排队。完成后显示账户和域名数量，读取失败会说明原因并保留原列表。首次访问凭据或系统重新要求授权时，仍可能出现系统授权窗口。

修复新域名只有邮件、验证或证书设置时被误判为不能接入的问题。没有网站地址记录时，可以确认后补齐网站解析，已有邮件和验证记录会保留。确认前会重新读取配置，发现变化或冲突则要求重新检查。

域名接入提供更明确的下一步：检查解析、核对修改、继续检查域名。填写目录时显示当前短链接样式。侧栏和更新窗口显示实际安装版本；有新版时同时显示当前版本与可更新版本。

各平台安装与原生验证结果以本版本 Release 记录为准；本机模拟测试不代表真实 Cloudflare 操作已完成。

# 0.1.5

域名接入增加 DNS 设置方案：空域名可创建短链接所需记录，已有地址可保持原值并开启代理。执行前列明改动并再次核对云端状态；权限不足、记录冲突和部分完成会分别说明。DNS 已设置成功但响应丢失时，可以重新检查并清除已解决的提示。

账户显示 Cloudflare 名称和本机备注，添加域名可从账户已有域名中选择，也可手填。新域名不在缓存中时会向 Cloudflare 补查，弹窗也可刷新列表；读取失败、令牌不可见和未启用的域名会区别说明。账户管理改为独立窗口，支持为指定账户更新令牌。

平台地址统一使用“官网链接”“大陆访问地址”和“邀请码”等名称。支持在各地址行识别完整邀请链接；短链接明确显示手动填写或跟随平台，以及大陆地址数量，平台修改不会影响未关联的手填链接。

短链接跳转与网站检查分开呈现。遇到本机虚拟 DNS 地址、网络限制等情况会说明未完成检测的原因，不将未知结果当作网站失效或大陆可达。

系统凭据采用 15 分钟内存缓存，减少连续操作的重复读取。关闭应用、更换令牌和到期清理会使缓存失效；取消或拒绝系统授权不再被误判成密钥丢失。首次访问或系统重新要求授权时仍可能弹窗。

各平台安装与原生验证结果以本版本 Release 记录为准。真实 Cloudflare 业务操作和大陆可达性不由本机模拟测试证明。

# 0.1.4

修复域名接入流程：网站把未知地址返回首页时，现在可以在明确确认短链接目录及其影响范围后，由软件自动配置跳转服务。无需为了接入而修改网站文件或补 404 页面。

检查结果区分「可接入」「确认后可接入」与「需要处理」，显示具体的 HTTP 状态或连接原因。域名归属、DNS、已有跳转服务冲突和访问限制仍会阻止不安全的操作。执行前再次核对当前配置与目录检查结果，发生变化时要求重新检查。

优化检查中的表单状态、返回重检和接入后的提示；更新安装完成后明确提示退出并重新打开应用。接入只为选定目录配置短链接服务，不修改 DNS、网站文件或访问保护规则。
