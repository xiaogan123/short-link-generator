# 0.1.0

首个候选版本提供账户管理、域名预检、短链接编辑、地区分流、共享地址池、目标访问检测、可选定时监测及配置找回。

- macOS：分别提供 Apple 芯片与 Intel 安装包。临时签名，未经过 Apple 公证。
- Windows：提供 x64 安装包，未做 Authenticode 签名。
- 应用更新使用 Tauri 签名验证；请核对公开下载来源和 SHA256SUMS。
- 地区自检验证路由选择；本机目标检测标注来源与时间，不能证明其他网络的访问结果。可选监测依赖用户配置的实际地区检测服务。

此文件是发布说明模板。草稿公开前，维护者必须补充该候选版本实际完成的平台、安装、更新、代理和云端验证结果及已知限制。
