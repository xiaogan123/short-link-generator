# 0.1.4

修复域名接入流程：网站把未知地址返回首页时，现在可以在明确确认短链接目录及其影响范围后，由软件自动配置跳转服务。无需为了接入而修改网站文件或补 404 页面。

检查结果区分「可接入」「确认后可接入」与「需要处理」，显示具体的 HTTP 状态或连接原因。域名归属、DNS、已有跳转服务冲突和访问限制仍会阻止不安全的操作。执行前再次核对当前配置与目录检查结果，发生变化时要求重新检查。

优化检查中的表单状态、返回重检和接入后的提示；更新安装完成后明确提示退出并重新打开应用。接入只为选定目录配置短链接服务，不修改 DNS、网站文件或访问保护规则。

# 0.1.1

安装包与各平台的验证结果以 GitHub Release 记录为准。选择与你的电脑匹配的安装包；`.app.tar.gz` 是 Mac 自动更新包，手动安装请下载 `.dmg`。Windows 手动安装使用 `.exe`。

## 验证说明

- 修改云端前仍需核对并确认操作范围。
- 本机检测、短链接跳转检查和可选大陆检测分别展示，不把未知结果当作可访问。
- macOS 使用临时签名，未经过 Apple 公证。
- Windows 安装包未做发布者签名，系统可能显示未知发布者。
- 应用更新包使用独立签名验证。请从本仓库的 Releases 页面下载，并核对 SHA256SUMS。
- 实际测试的系统版本会列在 Release 中；最低系统版本声明不等于在每个历史系统上逐一测试。
- 源码不附带真实账户、域名、邀请码或令牌。你在客户端保存的配置留在自己的电脑和 Cloudflare 账户中，私人导出文件不要上传到公开仓库。
