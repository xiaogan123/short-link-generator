# 使用指南

## 创建第一条短链接

1. 在 **Cloudflare 账户** 页面添加账户。按提示打开 Cloudflare，创建 API 令牌，再粘贴回软件。权限模板包含 Workers Scripts 编辑、Workers KV Storage 编辑、Workers Routes 编辑、Zone 读取、DNS 编辑和 Account Settings 读取。软件会验证令牌是否有效并读取可见资源；连接成功不代表已获得所有修改权限。
2. 在 **域名管理** 中选择账户已有的域名，也可手填子域名。软件先检查归属和现有配置，你确认后才会连接该域名。
3. 在 **短链接** 页面新建链接，选择域名，填写短链接名称，例如 `welcome`。
4. 选择直接填写两个完整网址，或使用已经保存的平台地址并填写自己的 **邀请码**。
5. 核对最终的短链接、跳转网址和修改范围，确认保存。随后可以检测和复制链接。

一个域名可以创建多条短链接，也可以只建一条。当前短链接格式为 `https://example.com/go/welcome`，其中 `go` 在添加域名时设置。

需要换一个短链接名称时，打开该链接的“编辑”，点击“换一个名称”。软件会带入当前填写的跳转设置和邀请码，填写新名称并确认后创建新链接，旧链接继续保留。新名称不能覆盖已有链接。两条链接以后各自管理；新地址确认可用后，可以按需删除旧链接，删除后旧地址将不再可用。

## 域名上已经有网站

选择一个专门用于短链接的目录，例如 `go`。软件只为 `example.com/go/` 及其下级地址添加跳转服务，不修改网站文件或其他目录的转发规则。

有些网站会在打开不存在的地址时显示首页，因此检查结果不一定是「页面不存在」。遇到返回网页、跳转或源站错误的情况，软件会显示黄色说明，并在下一步列出接入范围。确认使用该目录后，软件自动配置短链接服务。该目录原有的页面访问方式会被替换，没有创建的短链接会返回页面不存在；请先确认这个目录可以专门用来放短链接。

如果 DNS 尚未配置，或已有地址未开启代理，软件可列出设置方案。没有网站地址记录且没有冲突时，可补齐短链接所需解析，保留邮件和验证记录；已有可代理的地址只开启代理，保留原地址。核对后再执行，随后软件重新检查域名接入条件。DNS 代理会影响整个主机名的访问，请同时考虑已有网站；软件不会修改邮件记录，也不会覆盖存在冲突的配置。

旧令牌如果只有 DNS 读取权限，仍能使用原有功能；自动配置 DNS 需要 **Zone → DNS → Edit（区域 → DNS → 编辑）**，域名也须包含在令牌授权范围内。软件无法自行增加 Cloudflare 权限。遇到授权不足时，点击“修改已有令牌权限”，在浏览器中登录原令牌所属的 Cloudflare 用户，找到正在使用的令牌，通过右侧菜单“编辑”补上权限或域名范围。保留原有 Workers 等权限，保存后回到软件点击“已补好授权，继续检查”，无需重新粘贴原令牌。只有创建了新令牌或重新生成了令牌值，才需要通过账户管理中的“更换本机令牌”更新。域名归属不符、已有跳转服务占用目录、访问被拦截等问题仍需要按具体提示处理。

接入后创建第一条短链接，软件会自动检查跳转结果。Cloudflare 配置可能需要一点时间传播；网站已有的重定向规则或访问限制也可能继续生效，检测结果会据实显示。

## 多条链接共用一个平台地址

平台地址是本机工作空间的共用地址库，所有已导入账户和已接入域名都可以直接选用，无需逐个账户授权。先保存地址也可以，创建短链接时软件会自动配置到该域名所属账户。

在 **平台地址** 中新建一个平台，填写名称、官网链接和大陆访问地址。大陆地址可以填一个，也可以填多个，按从上到下的顺序优先选择。官网链接供中国大陆以外网络出口的访客使用；开启代理的访客也可能按其代理出口分流。

地址只填 **邀请码前面的部分**。例如：

| 邀请链接形式 | 邀请码前的地址 | 邀请码 |
| --- | --- | --- |
| 路径结尾 | `https://example.com/join/` | `DEMO123` |
| 查询参数 | `https://example.org/register?ref=` | `DEMO123` |
| 分享路径 | `https://example.org/zh/share/` | `DEMO123` |

如果邀请码后面还有 `&lang=zh` 之类的内容，可以展开高级设置后填入额外参数。域名必须完整，邀请码只能放在域名后面的路径或参数中。

以后域名变化时，只需要编辑该平台的备用地址。所有选择这个平台的短链接会随云端配置更新而使用新地址，**每条链接的邀请码保持原样**。直接填写网址的链接不会自动关联。需要改为共用地址时，编辑这条短链接，选择平台并核对邀请码后保存。平台显示“0 条关联链接”时，修改它不会影响任何现有手填链接。

保存前会列出受影响的账户和链接数量。若部分账户同步失败，按提示继续同步，确认每个账户都已更新。有链接仍在使用的平台地址不能删除。

## 看懂检测结果

| 结果 | 含义 | 可以怎么做 |
| --- | --- | --- |
| 红色警告 | 本次检测发现明确错误 | 查看是短链接还是跳转网站出错，修改后重测 |
| 黄色提示 | 超时、验证码、限流或其他原因，暂时无法确认 | 用需要的网络环境打开试试，稍后重新检测 |
| 绿色通过 | 本次相应检测通过 | 核对检测来源；本机通过不代表其他地区也能访问 |
| 灰色未测或过期 | 还没有当前配置的有效检测结果 | 运行一次新检测 |

软件分别检查 **短链接是否按配置跳转** 和 **跳转后的网站能否打开**。本机网站与跳转检查不使用应用层 HTTP 代理，但 VPN、TUN 和 DNS 设置仍可能影响结果。添加域名或检测链接时，如果无法检查是由 VPN 虚拟地址造成的，且没有其他阻断原因，软件会自动换用公共 DNS 重查一次。结果会注明自动切换，并显示这次检查是否通过；仍然失败时会保留具体原因。结果标明来源和时间，修改网址后需要重新检测。

需要手动重查时，可点击 **兼容 VPN 重试**；若短链接跳转检查也未通过，可选择 **兼容 VPN 重新检测跳转和网站**。添加域名时也可主动勾选 **兼容 VPN 网络**。软件会通过 Cloudflare 公共 DNS 查询真实地址，只向查询服务发送域名（网站继续跳转时也查询新域名），不发送完整链接、邀请码或账户令牌。此方式不更改电脑的 DNS 或 VPN 设置，结果仍只代表本机当前网络。查询失败或指向非公开地址时会停止；不会跳过目录检查或自动确认接管。

平台地址中的检测状态来自云端已保存的结果。读取状态不会立即启动新一轮检测。

网站本身还可能再次跳转到另一个域名，包括用网页脚本跳转。软件不会自动搜寻新域名；网站检测也不执行网页脚本，因此不能代替浏览器确认最终打开的页面。

## 自动避开打不开的大陆地址

此功能需要接入 **实际位于中国大陆网络的检测服务**。仅靠当前电脑或 Cloudflare 检测，无法判断所有大陆用户能否访问。

在 Cloudflare 账户菜单中填写可信的检测服务地址和密钥。可以使用兼容服务，或自行部署仓库中的 [参考检测服务](../probe/README.md)。软件不会自动购买或创建检测节点。

开启后，关闭客户端也会继续云端检测。连续三次明确失败的地址会暂时停用，连续两次成功后恢复。无法确认的结果不会当成成功或失败；旧结果过期后显示为无法确认。如果近期检测确认所有备用地址都不可用，会显示暂时不可用，不自动跳到其他地区的地址。

每个账户超过 60 个启用备用地址时，逐个检查可能接近结果过期时间，需要减少地址或分配到不同账户。关闭监测会保留已有的平台地址和短链接。

## 系统授权提示

Mac 旧账户如果显示「需要更新本机授权」，打开该账户的管理窗口，选择 **更新本机授权**，核对后确认。软件会将这个账户的本机凭据复制到由新版保存的钥匙串条目中，云端配置和待处理记录保持不变。系统可能分别询问不同凭据的访问权限；取消或失败后，软件会停止本次处理，不会继续连弹。处理成功后，重新执行刚才的操作即可。

旧版凭据迁移只需为每个旧账户成功完成一次；这不代表以后升级客户端无需系统授权。当前 Mac 自签版本更新后，系统可能按新的程序指纹再次询问，即使上次已允许访问。此情况不代表 Cloudflare 令牌失效，不需要因此删除令牌或重复迁移。

日常刷新不会自动重复读取旧版条目。旧条目会保留；以后更换令牌或检测密钥后，请继续使用新版，避免旧客户端读到过时的凭据。换电脑或导入备份不代表已获得这台电脑的钥匙串授权。

令牌和检测密钥仍保存在系统凭据库，软件不保存系统密码。已读取的凭据在内存中短时复用：30 分钟未使用或从系统读取、更新后满 8 小时停止复用，关闭应用后清除。缓存失效会重新读取系统凭据库，并不代表一定要再次输入密码。系统钥匙串锁定或你为条目另设访问限制时，系统仍可能要求授权。只在系统自己的窗口中输入密码，不需要允许其他应用读取凭据。详见 [Apple 的钥匙串授权说明](https://support.apple.com/guide/keychain-access/kyca1243/mac)。

## 检测密钥需要恢复

黄色恢复提示会标明对应账户，请按账户名称或本机备注核对，不要按列表中的先后位置判断。检测密钥用于软件检查短链接跳转，与连接 Cloudflare 的 API 令牌不同。能够刷新该账户的域名列表时，不需要因为检测密钥提示而删除令牌或重新导入账户。

旧版操作如果同时缺少本机服务配置，先选择 **找回本机检测配置** 并核对计划。此步骤只读取 Cloudflare 并补回经过核验的本机配置，保留已有短链接和待处理记录。没有找到、找到多个或无法核验时会停止并说明原因。

找回配置后，再打开该账户的检测密钥修复计划并确认。该操作可能更新云端检测密钥，使用同一账户的其他电脑也可能需要同步处理。软件不会在找回配置后自动更新密钥，也不会仅为消除黄色提示而删除未完成记录。

## 删除与备份

删除短链接成功后，它对应的 Cloudflare 配置也会删除。域名、共享的跳转服务和平台地址会继续保留。缓存和云端同步需要时间，各地不一定立即生效。

移除账户会清除本机账户记录及新版使用的凭据。Mac 迁移时保留的旧版钥匙串条目不会在这一步自动删除，也不会继续用于日常操作。

导出备份不包含 API 令牌和检测密钥，但包含你的域名、邀请码与跳转网址，请私下保存。恢复时仍需连接相应账户；目前备份导入上限为 500 个域名、20,000 条链接、256 组平台地址和 2 MB 文件。不要把这组上限当成 Cloudflare 账户额度。

## 自己做一次完整验收

使用独立测试域名，完成添加账户、连接域名、创建链接和检测。再创建一个平台地址，用两个不同邀请码生成短链接，修改一次大陆备用地址，确认两条链接一起更新且邀请码不变。

用确定不存在的网页检查红色警告，再使用正常网页重测。分别在各操作系统上检查系统代理开启、关闭时的行为。

自动监测需要独立的测试服务。模拟三次失败、两次成功和无法确认的结果，检查停用、恢复、时间和来源是否正确。完成后删除测试链接，在 Cloudflare 核对对应记录；清理共享服务需要单独确认。

新买的域名没有出现在列表时，可在添加域名窗口点击“刷新域名列表”。直接输入新域名并检查时，软件也会补查 Cloudflare。若仍找不到，请确认域名所属账户，以及令牌允许访问该域名；软件不会自行扩大令牌权限。
