# 使用指南

## 创建第一条短链接

1. 在 **Cloudflare 账户** 页面添加账户。按提示打开 Cloudflare，创建 API 令牌，再粘贴回软件。权限模板包含 Workers Scripts 编辑、Workers KV Storage 编辑、Workers Routes 编辑、Zone 读取、DNS 读取和 Account Settings 读取；软件会验证权限。
2. 在 **域名管理** 中添加自己的域名。软件先检查归属和现有配置，你确认后才会连接该域名。
3. 在 **短链接** 页面新建链接，选择域名，填写短链接名称，例如 `welcome`。
4. 选择直接填写两个完整网址，或使用已经保存的平台地址并填写自己的 **邀请码**。
5. 核对最终的短链接、跳转网址和修改范围，确认保存。随后可以检测和复制链接。

一个域名可以创建多条短链接，也可以只建一条。当前短链接格式为 `https://example.com/go/welcome`，其中 `go` 在添加域名时设置。

## 多条链接共用一个平台地址

在 **平台地址** 中新建一个平台，填写名称、其他地区使用的地址，以及中国大陆使用的备用地址。大陆备用地址可以填一个，也可以填多个，按从上到下的顺序优先使用。

地址只填 **邀请码前面的部分**。例如：

| 邀请链接形式 | 邀请码前的地址 | 邀请码 |
| --- | --- | --- |
| 路径结尾 | `https://example.com/join/` | `DEMO123` |
| 查询参数 | `https://example.org/register?ref=` | `DEMO123` |
| 分享路径 | `https://example.org/zh/share/` | `DEMO123` |

如果邀请码后面还有 `&lang=zh` 之类的内容，将它填入额外参数。域名必须完整，邀请码只能放在域名后面的路径或参数中。

以后域名变化时，只需要编辑该平台的备用地址。所有选择这个平台的短链接会随云端配置更新而使用新地址，**每条链接的邀请码保持原样**。直接填写网址的链接需要单独修改。

保存前会列出受影响的账户和链接数量。若部分账户同步失败，按提示继续同步，确认每个账户都已更新。有链接仍在使用的平台地址不能删除。

## 看懂检测结果

| 结果 | 含义 | 可以怎么做 |
| --- | --- | --- |
| 红色警告 | 本次检测发现明确错误 | 查看是短链接还是跳转网站出错，修改后重测 |
| 黄色提示 | 超时、验证码、限流或其他原因，暂时无法确认 | 用需要的网络环境打开试试，稍后重新检测 |
| 绿色通过 | 本次相应检测通过 | 核对检测来源；本机通过不代表其他地区也能访问 |
| 灰色未测或过期 | 还没有当前配置的有效检测结果 | 运行一次新检测 |

软件分别检查 **短链接是否按配置跳转** 和 **跳转后的网站能否打开**。网站检测由当前电脑直接连接，不经过系统代理，因此可能与开启代理的浏览器结果不同；账户连接和短链接跳转检查仍使用系统代理设置。结果会标明来源和时间，修改网址后需要重新检测。

平台地址中的检测状态来自云端已保存的结果。读取状态不会立即启动新一轮检测。

网站本身还可能再次跳转到另一个域名，包括用网页脚本跳转。软件不会自动搜寻新域名；网站检测也不执行网页脚本，因此不能代替浏览器确认最终打开的页面。

## 自动避开打不开的大陆地址

此功能需要接入 **实际位于中国大陆网络的检测服务**。仅靠当前电脑或 Cloudflare 检测，无法判断所有大陆用户能否访问。

在 Cloudflare 账户菜单中填写可信的检测服务地址和密钥。可以使用兼容服务，或自行部署仓库中的 [参考检测服务](../probe/README.md)。软件不会自动购买或创建检测节点。

开启后，关闭客户端也会继续云端检测。连续三次明确失败的地址会暂时停用，连续两次成功后恢复。无法确认的结果不会当成成功或失败；旧结果过期后显示为无法确认。如果近期检测确认所有备用地址都不可用，会显示暂时不可用，不自动跳到其他地区的地址。

每个账户超过 60 个启用备用地址时，逐个检查可能接近结果过期时间，需要减少地址或分配到不同账户。关闭监测会保留已有的平台地址和短链接。

## 删除与备份

删除短链接成功后，它对应的 Cloudflare 配置也会删除。域名、共享的跳转服务和平台地址会继续保留。缓存和云端同步需要时间，各地不一定立即生效。

导出备份不包含 API 令牌和检测密钥，但包含你的域名、邀请码与跳转网址，请私下保存。恢复时仍需连接相应账户；目前备份导入上限为 500 个域名、20,000 条链接、256 组平台地址和 2 MB 文件。不要把这组上限当成 Cloudflare 账户额度。

## 自己做一次完整验收

使用独立测试域名，完成添加账户、连接域名、创建链接和检测。再创建一个平台地址，用两个不同邀请码生成短链接，修改一次大陆备用地址，确认两条链接一起更新且邀请码不变。

用确定不存在的网页检查红色警告，再使用正常网页重测。分别在各操作系统上检查系统代理开启、关闭时的行为。

自动监测需要独立的测试服务。模拟三次失败、两次成功和无法确认的结果，检查停用、恢复、时间和来源是否正确。完成后删除测试链接，在 Cloudflare 核对对应记录；清理共享服务需要单独确认。
