# 使用指南

## 从账户到第一条链接

1. 打开 **账户 → 导入账户**，在系统浏览器中创建令牌，复制后粘贴回客户端。检查模板只选择 Workers Scripts 编辑、Workers KV Storage 编辑、Workers Routes 编辑、Zone 读取、DNS 读取、Account Settings 读取。客户端会验证权限。
2. 打开 **域名 → 添加域名**，粘贴精确主机名或完整网址。检查所属账户、代理 DNS、路径和路由冲突；确认变更计划后才写入。
3. 临时单条链接可选 **短链接 → 新建链接 → 手动填写**，填写两个完整 HTTPS 目标。
4. 需要统一维护时，先创建 **地址池**：填写其他地区目标前缀、一个或多个大陆目标前缀，必要时补充代码后的后缀，并选择使用该池的账户。随后创建短链接时选 **共享地址池**，只填每条链接自己的代码。
5. 阅读并确认变更。保存后自动检测跳转和目标网址，可复制完整短链接。

路径型前缀示例：`https://example.com/join/`，后缀留空。查询参数型前缀示例：`https://example.org/start?code=`，后缀可填 `&lang=zh`。代码只能位于完整主机名后的路径或查询参数中。访客带入的参数不能覆盖配置好的目标。

## 看懂检测结果

| 结果 | 含义 | 下一步 |
| --- | --- | --- |
| 红色失败 | 该项检测观察到明确错误 | 查看错误来自短链接还是目标网站，修改后重测 |
| 黄色未知 | 超时、验证码、限流、证据不足或其他不确定结果 | 在需要的网络环境中重测，不把它当成明确不可用 |
| 绿色本机通过 | 当前机器上的跳转与目标检测均通过 | 这不代表所有地区都能访问 |
| 灰色未测或过期 | 当前配置还没有有效证据 | 运行一次新检测 |

目标检测走本机直连，不经过系统代理，与浏览器使用代理时的结果可能不同；账户 API 与短链接自检仍遵循系统代理设置。结果会标明来源和时间。修改链接或它引用的池后，旧结果会失效。地址池的「读取检测状态」读取云端已保存的服务结果，不会立即发起一轮新检测。

## 统一换一个目标地址

编辑地址池前缀，核对受影响账户、关联链接数量和完整目标后确认。引用该池的全部短链接会随着云端配置传播使用新模板，各自的代码保留。手动模式链接独立维护。

查看每个账户的同步状态。有失败时，先处理失败并重新同步，再确认所有账户都采用新地址。有引用的池不能删除；需要先修改或删除关联链接。停用的候选不会被选中，从上到下是访问优先级。

## 可选大陆监测

在账户菜单中配置可信的 HTTPS 检测服务地址和密钥。可以使用兼容服务，或将 [参考检测服务](../probe/README.md) 部署在实际中国大陆网络。软件不会自动创建这类节点或购买服务。确认计划时核对服务地址、Worker 密钥、监测记录和定时任务。

开启后，客户端关闭也会继续云端检测。连续三次明确失败后隔离候选，连续两次成功后恢复。未知结果会打断连续计数；已隔离候选保持隔离但不刷新有效时间，证据过期后恢复为未知。每个账户超过 60 个启用候选时，轮转可能接近证据过期窗口，应减少目标或分布到不同账户。关闭监测保留所有池和链接。

## 自己做一次完整验收

使用自己的独立测试域名。在浏览器确认令牌模板权限，导入账户、添加域名、创建一条手动链接，检查两个地区的跳转结果。再建一个池，创建两条使用不同代码的短链接；修改一次池前缀，确认两个目标一起变化且代码保持不同。

用一个确定不存在的目标页面测试红色告警，再用正常页面测试。分别在每个操作系统上检查系统代理开启和关闭的行为。

测试监测功能时，在独立测试服务中返回签名的模拟结果：三次失败应隔离，一次成功尚不恢复，第二次成功恢复；未知结果应打断连续计数。核对显示的来源、账户和时间。

验收后在客户端移除测试链接与域名，再到云端核对路由和 KV 记录确实删除。剩余账户资源通过单独的清理操作处理。不要拿现有网站的资源执行这套验收。
